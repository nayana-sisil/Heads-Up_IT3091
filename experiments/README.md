# Experiments

Each member has their own folder for individual experimentation, tied to their own branch of the same name:

| Folder | Branch |
|---|---|
| `nayana_dev1/` | `nayana_dev1` |
| `heshan_dev2/` | `heshan_dev2` |
| `asindi_dev3/` | `asindi_dev3` |
| `heshani_dev4/` | `heshani_dev4` |

**Rules:**
- Only commit to your own folder while on your own branch — keeps diffs clean and avoids merge conflicts.
- This is a sandbox: try models, save configs, dump `metrics.json`, whatever helps you iterate.
- Once something is ready to become part of the shared pipeline (`src/`, `notebooks/`), open a Pull Request into `main` so the group can review it before it's merged.
- Dev branches don't need to be deleted after merging — they're ongoing personal workspaces for the whole project.
